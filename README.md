# sinfonion-navigator

travelers guide for piloting your starship: a one-page reference for the **acl sinfonion** harmonic cv processor, firmware 1.0. the three quantizers, chords, arpeggiator, scales and modes, the chord progression sequencer, the oct and song pages, the matrices, every cv / in / out function and the hidden combos, with diagrams.

source: the acl sinfonion user manual (firmware 1.0).

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with acl / audiophile circuits league or mathias kettner.
